# Glass-Webseite (Jekyll + GitHub Pages)

**Inhalte:** Markdown-Dateien (`index.md`, `ueber-mich/index.md`, …)
**Einstellungen:** `_config.yml` (Titel, Logo, Footer)
**Menü:** `_data/navigation.yml`
**Karten:** `_data/projekte.yml`
**Design:** `assets/css/style.css` (Farben ganz oben in `:root`)
**Logo:** `assets/img/logo.svg` ersetzen oder in `_config.yml` anderen Pfad eintragen

## Veröffentlichen
1. Dateien in ein GitHub-Repository hochladen
2. Repository → Settings → Pages → Source: „Deploy from a branch“ → `main` / `/ (root)`
3. Nach ca. 1 Minute ist die Seite online
